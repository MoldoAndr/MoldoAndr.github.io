- **Live Site**: [https://moldoandr.github.io](https://moldoandr.github.io)

## 📄 Pages

### Home (`index.html`)
- Stunning landing page with WebGL fluid simulation background
- Neon noir dark theme with glassmorphic design
- Navigation to Demo and Documentation

### Frontend Demo (`demo.html`)

## 🎨 Design System

The site uses a sophisticated dark theme with vibrant neon green accents (#00ff88):

- **Background**: Pure black (#000000) with glassmorphism
- **Accent**: Electric green (#00ff88) with glow effects
- **Typography**: Inter font family for clean, modern look
- **Effects**: WebGL fluid simulation, backdrop blur, smooth animations

## 🛠️ Technologies

- **HTML5/CSS3**: Modern static markup and styling
- **Vanilla JavaScript**: No framework dependencies
- **WebGL**: Interactive fluid simulation background
- **Responsive Design**: Mobile-first approach

## 🚀 Deployment

The site is automatically deployed to GitHub Pages. To update:

1. Push changes to the `main` branch
2. GitHub Actions will build and deploy automatically
3. Changes will be live within minutes
